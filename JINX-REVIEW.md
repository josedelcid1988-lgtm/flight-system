Problem: `backup()` spawns `pg_dump` with the full `FLIGHT_DATABASE_URL` connection URI stuffed into the `PGDATABASE` environment variable. Per PostgreSQL docs, `PGDATABASE` is a database *name*, not a URI; libpq treats the URI literally as a name and the connection fails.
