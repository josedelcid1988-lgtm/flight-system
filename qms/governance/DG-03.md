# DG-03: Optional model adapter control

**Status:** Controlled-document draft for Quality review

## Default and ownership

The model adapter is off by default. Deterministic Flight rules continue to operate with it disabled. Only the QA Manager or Master Access may change the adapter configuration, with a rationale captured in the signed QMS configuration history.

## Secret handling

The workspace stores only the provider name, enabled state and server environment-setting name. The secret value is held by the server environment or secret manager. It is never accepted by the browser, written to the workspace, copied into the AI action log, returned by an API, or included in an evidence export.

## Permitted use

An enabled adapter may produce a draft narrative for an approved, validated skill. It cannot sign, approve, release, close, disposition, alter measurements, or bypass any Flight gate. A missing key, disabled adapter, refused provider response, timeout or malformed response fails closed to a human-readable message; it does not change the target record.

## Review and revalidation

Quality approves the use case, provider, data categories, retention, validation, risk treatment and human acceptance path before enabling. Provider, model, endpoint, key setting, prompt or input-scope changes are configuration changes and require review. Validate both adapter-off and adapter-on behavior.
