# DG-01 automation job description template

Complete and approve this template before enabling an automation.

| Field | Required entry |
| --- | --- |
| Tool or skill name and version |  |
| Accountable owner | Person and role |
| Intended purpose | Specific record and decision supported |
| Prohibited uses | Decisions or records the tool cannot make or change |
| Method | Deterministic method or approved model provider |
| Inputs and sources | Fields, record identifiers and permitted data categories |
| Outputs | Draft fields, analysis and record destinations |
| Human review | Required qualification, separation of duties and final approval chain |
| Risks and controls | Risks, severity, mitigations and residual risk owner |
| Validation | Fixtures, acceptance criteria, failure cases and results |
| Logging | Version, actor, time, input/output hashes and record references |
| Data handling | Storage, provider transfer, retention and access |
| Release and rollback | Approver, effective version, disable action and withdrawal record |
| Revalidation triggers | Changes that require validation before use |

This template is not an approval. Import the completed and signed copy into the Flight controlled document register.
